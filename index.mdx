Raigal checks code for patterns introduced by AI coding tools, including verbose comments, unnecessary type assertions, swallowed errors, and insecure calls. It combines formatting, linting, complexity checks, security rules, and pattern detection into one CLI command that returns a calibrated score from 0 to 100.

Used with the [Raigal Cloud Platform](https://app.raigal.dev) and the official [Raigal GitHub App](https://github.com/apps/raigal-cloud), it evaluates pull requests, updates status checks for branch protection, tracks issues on a 4-stage remediation board, and coordinates repair sessions with local coding agents.

<Info>
  Raigal runs AST parsing, linting, and pattern checks locally inside your runner. Full source code is never uploaded to Raigal servers. During pull request CI evaluations, an in-memory secret-masked git patch diff preview (up to 20 KB) is sent to render the PR dashboard. Autonomous repair sessions (`raigal agent`) communicate with your configured local LLM provider.
</Info>

## What Raigal catches

Coding assistants such as Claude Code, Cursor, Copilot, and OpenCode speed up feature delivery, but frequently leave behind structural defects:

* Narrative comments that repeat function signatures or obvious statements.
* Swallowed exceptions in `catch` blocks that hide runtime failures.
* Unsafe type assertions (`as any`, `as unknown as T`) introduced to bypass compiler checks.
* Leftover debugging statements, console calls, and unreachable branches.
* Unsanitized SQL interpolations, dynamic `eval()` calls, and unsandboxed agent tools.

Raigal runs through local agent hooks, in CI pipelines on every pull request, and during manual terminal audits.

## Getting started

<Steps>
  <Step title="1. Sign in to Raigal Cloud">

Create an organization workspace at [app.raigal.dev](https://app.raigal.dev) with a 14-day evaluation trial and invite your team. [Organization Onboarding Guide](/getting-started/first-client-setup)

  </Step>

  <Step title="2. Install the Raigal GitHub App">

Connect your repositories through the [Raigal GitHub App](https://github.com/apps/raigal-cloud) to run status checks on pull requests. [Pull Request Quality Gate](/automation-and-ci-cd/pull-requests)

  </Step>

  <Step title="3. Add the CI workflow">

Add a pinned GitHub Actions workflow to check pull requests and send scores to your dashboard. [CI/CD Pipelines & GitHub Actions](/automation-and-ci-cd/ci-cd)

  </Step>

  <Step title="4. Set up local tools and hooks">

Install the CLI (`raigal scan`, `raigal fix`) and set up interception hooks for Claude Code or Cursor. [Quickstart Guide](/getting-started/quickstart)

  </Step>
</Steps>
