title: "Raigal overview"
description: "Code quality and AI pattern detection for engineering teams."

Raigal catches the sloppy patterns AI coding tools leave behind: redundant comments, swallowed errors, unsafe type casts, and insecure calls. It packages linting, formatting, security checks, and pattern detection into one CLI command with a calibrated score from 0 to 100.

Connected to [Raigal Cloud](https://app.raigal.dev) and the official [Raigal GitHub App](https://github.com/apps/raigal-cloud), it evaluates pull requests, protects main branches, tracks issues on a 4-stage board, and coordinates automated fixes with local coding agents.

<Info>
  Raigal runs AST parsing, linting, and pattern checks locally inside your runner. Your source code is never uploaded to Raigal servers. During pull request checks, an in-memory secret-masked patch diff (under 20 KB) is sent to display changes in the dashboard.
</Info>

## What Raigal catches

AI assistants like Claude Code, Cursor, Copilot, and OpenCode speed up development, but frequently leave behind structural defects:

* Narrative comments that repeat function names or obvious code.
* Empty `catch` blocks that hide runtime failures.
* Unsafe type assertions (`as any`, `as unknown as T`) that bypass the compiler.
* Leftover debugging statements, console logs, and unreachable branches.
* Unsanitized SQL, dynamic `eval()`, and unsandboxed agent tools.

Raigal runs through local agent hooks, in CI on every pull request, and during terminal audits.

## Getting started

<Steps>
  <Step title="1. Sign in to Raigal Cloud">

Create a workspace at [app.raigal.dev](https://app.raigal.dev) with a 14-day evaluation trial and invite your team. [Organization onboarding guide](/getting-started/first-client-setup)

  </Step>

  <Step title="2. Install the Raigal GitHub App">

Connect your repositories with the [Raigal GitHub App](https://github.com/apps/raigal-cloud) to run checks on pull requests. [Pull request checks](/automation-and-ci-cd/pull-requests)

  </Step>

  <Step title="3. Add the CI workflow">

Add a GitHub Actions workflow to check pull requests and send scores to your dashboard. [CI/CD pipelines](/automation-and-ci-cd/ci-cd)

  </Step>

  <Step title="4. Set up local tools and hooks">

Install the CLI (`raigal scan`, `raigal fix`) and set up interception hooks for Claude Code or Cursor. [Quickstart guide](/getting-started/quickstart)

  </Step>
</Steps>
