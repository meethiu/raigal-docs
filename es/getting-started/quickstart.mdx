---
title: "Inicio rápido"
description: "Inicia sesión, genera la configuración, lanza un escaneo y aplica arreglos automáticos en pocos minutos."
---

Evalúa la salud de tu código y obtén una puntuación en cuatro pasos.

<Steps>
  <Step title="1. Inicia sesión en tu organización">

Conecta tu terminal local con Raigal Cloud:

```bash
npx @methiu/raigal login
```

Esto abrirá el navegador para autorizar tu equipo. Si trabajas en un servidor sin entorno gráfico, contenedor Docker o runner de CI, exporta tu token directamente:

```bash
export RAIGAL_TOKEN="rgl_live_tu_token_aqui"
```

<Info>
  Las organizaciones nuevas en [app.raigal.dev](https://app.raigal.dev) cuentan con 14 días de prueba con acceso total a los seis motores de análisis.
</Info>

</Step>

  <Step title="2. Inicializa la configuración del proyecto">

Genera los archivos de configuración adaptados a tu repositorio:

```bash
npx @methiu/raigal init
```

El asistente detecta tus dependencias y crea automáticamente:
- `.raigal/config.yml`: umbrales de puntuación, motores activos y archivos excluidos.
- `.raigal/rules.yml`: severidades personalizadas y reglas de arquitectura.
- Plantilla de CI para GitHub Actions, GitLab CI o Bitbucket Pipelines.

</Step>

  <Step title="3. Ejecuta tu primer análisis">

Lanza el escaneo desde la raíz del proyecto:

```bash
npx @methiu/raigal scan .
```

Raigal ejecuta en paralelo los motores de formato, linters, calidad, patrones de IA, arquitectura y seguridad, devolviendo una nota de 0 a 100:

```text
   94 / 100  Healthy       0 errors  ·  1 warning  ·  1 fixable
   12 files  ·  6 engines  ·  48ms

 Top findings
   #  Finding                 Rule                       Status
   1  console.log leftover    ai-slop/console-leftover   warn [auto]
```

Para ver la lista exacta de archivos y líneas afectadas, añade `-d`:

```bash
npx @methiu/raigal scan . -d
```

</Step>

  <Step title="4. Aplica correcciones automáticas">

Corrige de forma segura problemas de formato, importaciones sin usar y comentarios redundantes:

```bash
npx @methiu/raigal fix .
```

Si prefieres ver qué cambiaría antes de tocar los archivos, usa `--dry-run`:

```bash
npx @methiu/raigal fix . --dry-run
```

Para problemas complejos que requieran refactorización (como excepciones silenciadas o conversiones de tipo inseguras), ejecuta `npx @methiu/raigal agent .` para abrir una sesión de reparación aislada con Claude Code, Cursor u OpenCode.

</Step>
</Steps>
