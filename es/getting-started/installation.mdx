---
title: "Instalación"
description: "Cómo instalar la CLI de Raigal mediante npm, npx, pnpm, yarn o bun en macOS, Linux y Windows."
---

Puedes ejecutar Raigal al instante sin instalar nada usando `npx`, instalarlo de forma global en tu máquina o añadirlo a las dependencias de tu proyecto.

## Requisitos del sistema

- **Node.js**: versión 20.12 o superior (recomendado Node 22 LTS)
- **Gestor de paquetes**: `npm`, `pnpm`, `yarn` o `bun`
- **Sistemas operativos**: macOS, Linux o Windows (PowerShell y cmd.exe)

## Ejecutar directamente con `npx`

Lanza un análisis rápido sin instalar nada de forma permanente:

```bash
npx --yes @methiu/raigal@latest scan .
```

Inicia el asistente interactivo de configuración:

```bash
npx --yes @methiu/raigal@latest init
```

## Instalación global

Instala Raigal de forma global para tener el comando `raigal` siempre disponible en cualquier terminal:

<Tabs>
  <Tab title="npm">

```bash
npm install -g @methiu/raigal
```

  </Tab>

  <Tab title="pnpm">

```bash
pnpm add -g @methiu/raigal
```

  </Tab>

  <Tab title="yarn">

```bash
yarn global add @methiu/raigal
```

  </Tab>

  <Tab title="bun">

```bash
bun add -g @methiu/raigal
```

  </Tab>
</Tabs>

Comprueba que la CLI responde correctamente:

```bash
raigal --version
```

## Como dependencia del proyecto

Añade Raigal como dependencia de desarrollo en tu repositorio:

<Tabs>
  <Tab title="npm">

```bash
npm install -D @methiu/raigal
```

  </Tab>

  <Tab title="pnpm">

```bash
pnpm add -D @methiu/raigal
```

  </Tab>

  <Tab title="yarn">

```bash
yarn add -D @methiu/raigal
```

  </Tab>

  <Tab title="bun">

```bash
bun add -d @methiu/raigal
```

  </Tab>
</Tabs>

Añade estos atajos a tu `package.json`:

```json
{
  "scripts": {
    "scan": "raigal scan .",
    "gate": "raigal ci .",
    "fix": "raigal fix ."
  }
}
```

Así cualquier miembro del equipo puede ejecutar `pnpm scan` o `npm run gate` con las mismas reglas de forma consistente.
