Raigal Cloud proporciona una API REST para consultar puntuaciones, inspeccionar políticas activas, gestionar tokens e ingerir resultados de la CLI.

## Autenticación

Todas las solicitudes deben incluir un token Bearer válido en la cabecera `Authorization`:

```http
Authorization: Bearer rgl_live_tu_clave_api_aqui
```

<Info>
  Genera claves de API en [app.raigal.dev/settings](https://app.raigal.dev/settings) en la sección **API Tokens**.
</Info>

## Endpoints

### 1. Comprobación de identidad
Verifica el token activo y devuelve el usuario autenticado, organización, estado de la prueba o licencia, y propietarios de repositorios autorizados.

```http
GET /v1/whoami
```

Respuesta:
```json
{
  "user": {
    "id": "user_2tQ...",
    "email": "dev@acme.com"
  },
  "org": {
    "id": "org_2tQ...",
    "name": "Acme Engineering",
    "status": "active"
  },
  "plan": "active",
  "trial_started_at": null,
  "trial_ends_at": null,
  "allowed_owners": [
    {
      "id": 1234567,
      "login": "acme"
    }
  ]
}
```

### 2. Política de calidad de la organización
Recupera los umbrales de calidad y las reglas bloqueadas para la organización o para un repositorio concreto.

```http
GET /v1/policy?repo=acme%2Fbackend-api
```

Respuesta:
```json
{
  "version": 1,
  "hash": "7b8f9a2e...",
  "config": {
    "ci": {
      "failBelow": 80
    },
    "rules": {
      "ai-slop/swallowed-exception": "error"
    },
    "exclude": []
  },
  "locked": [
    "ci.failBelow",
    "rules.ai-slop/swallowed-exception"
  ]
}
```

### 3. Ingesta de ejecuciones de la CLI
Envía un informe de análisis generado por la CLI (`raigal ci` o `raigal scan`):

```http
POST /v1/runs
Content-Type: application/json
```

## Gestión de tokens

Los tokens se pueden crear en el panel web o mediante la API de tokens:

### Crear token de API
```http
POST /api/tokens
Content-Type: application/json

{
  "name": "Production Deploy Runner"
}
```

Respuesta:
```json
{
  "token": "rgl_live_8f3a9b1c7e2d...",
  "prefix": "rgl_live_8f3a",
  "name": "Production Deploy Runner",
  "id": "key_9b2e...",
  "created_at": "2026-10-21T10:00:00.000Z"
}
```

<Warning>
  Guarda tu token nada más crearlo. El valor completo se muestra una sola vez. Raigal Cloud solo guarda el hash SHA-256 y no puede recuperar tokens perdidos.
</Warning>

### Gestión de repositorios y panel web

La gestión de proyectos, ramas activas y revocación de tokens se realiza desde la interfaz web en [app.raigal.dev/settings](https://app.raigal.dev/settings) con tu sesión autenticada del navegador.
