El servidor Model Context Protocol (MCP) de Raigal conecta los motores de análisis y calidad directamente con tus asistentes de código e IDEs mediante `npx --yes @methiu/raigal@latest mcp`.

## Requisitos y autenticación

Raigal MCP se autentica de dos formas:

- Sesión local: si ya ejecutaste `raigal login` en tu equipo, el servidor detecta tus credenciales locales automáticamente sin necesidad de tokens adicionales.
- Variable de entorno: en servidores sin interfaz gráfica o CI, pasa tu clave con `RAIGAL_TOKEN=rgl_live_...`.

## Configuración de clientes

<Tabs>
  <Tab title="Claude Code">

Ejecuta este comando en tu terminal:

```bash
claude mcp add raigal -- npx --yes @methiu/raigal@latest mcp
```

Si necesitas pasar el token explícitamente:

```bash
claude mcp add raigal -e RAIGAL_TOKEN=rgl_live_... -- npx --yes @methiu/raigal@latest mcp
```

  </Tab>

  <Tab title="Cursor">

1. Abre los ajustes de Cursor con `Cmd + ,` o `Ctrl + ,`.
2. Ve a **Features** > **MCP**.
3. Pulsa en **Add New MCP Server**.
4. Rellena los campos:
   - Nombre: `raigal`
   - Tipo: `command`
   - Comando: `npx --yes @methiu/raigal@latest mcp`

También puedes configurarlo en `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "raigal": {
      "command": "npx",
      "args": ["--yes", "@methiu/raigal@latest", "mcp"],
      "env": {
        "RAIGAL_TOKEN": "rgl_live_TU_TOKEN_AQUI"
      }
    }
  }
}
```

  </Tab>

  <Tab title="Claude Desktop">

Añade el servidor a tu archivo de configuración de Claude Desktop:
- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json

    "raigal": {
      "command": "npx",
      "args": ["--yes", "@methiu/raigal@latest", "mcp"],
      "env": {

      }
    }
  }
}
```

  </Tab>

## Herramientas disponibles

Una vez conectado, los asistentes pueden invocar cuatro herramientas:

| Herramienta | Descripción |
|---|---|
| `raigal_scan` | Analiza el repositorio buscando defectos (comentarios obvios, errores silenciados, conversiones `as any`), problemas de seguridad, linters y formato, devolviendo una nota de 0 a 100. |
| `raigal_fix` | Aplica correcciones automáticas y seguras para los problemas detectados. |
| `raigal_why` | Explica por qué saltó una regla concreta y ofrece consejos para solucionarla. |
| `raigal_baseline` | Crea o actualiza una línea base para que el asistente se centre únicamente en los cambios nuevos. |

## Instrucciones para prompts de agentes

Para que los asistentes verifiquen su trabajo antes de dar una tarea por terminada, añade este texto a `AGENTS.md`, `CLAUDE.md` o al prompt de tu agente:

```markdown wrap
Antes de entregar cambios en el código, ejecuta la herramienta MCP `raigal_scan` para verificar que no hay malos patrones de IA, errores silenciados ni regresiones de tipos. Si encuentras incidencias, utiliza `raigal_fix` o corrígelas antes de terminar.
```
