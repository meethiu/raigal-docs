Raigal incluye comandos para análisis locales, correcciones automáticas, sesiones de reparación con agentes y validación en CI.

## Índice de comandos

| Comando | Acción |
|---|---|
| `raigal [dir]` | Menú interactivo en terminal o escaneo predeterminado |
| `raigal scan [dir]` | Ejecuta el escaneo de calidad y devuelve la puntuación |
| `raigal fix [dir]` | Aplica correcciones automáticas seguras o genera prompts para agentes |
| `raigal ci [dir]` | Control de calidad con códigos de salida en CI/CD |
| `raigal agent [dir]` | Sesiones de reparación en worktrees aislados (Claude, Cursor, OpenCode) |
| `raigal hook` | Gestiona hooks en tiempo real para asistentes de código |
| `raigal report-pr-closed` | Notifica el cierre o fusión de pull requests a Raigal Cloud |
| `raigal telemetry` | Inspecciona el paquete enviado al panel web y la cola de salida |
| `raigal login` | Inicio de sesión mediante navegador OAuth o token de API |
| `raigal logout` | Limpia credenciales locales y licencias sin conexión en caché |
| `raigal whoami` | Muestra usuario, organización, estado del plan y repositorios autorizados |
| `raigal doctor` | Comprueba las herramientas instaladas, linters y motores del sistema |
| `raigal rules` | Muestra el catálogo de reglas y pesos de puntuación |
| `raigal init` | Crea el archivo de configuración y el flujo de CI |
| `raigal mcp` | Ejecuta el servidor Model Context Protocol (MCP) por stdio |

## Referencia de comandos

### `raigal scan`

Analiza el directorio indicado y muestra el desglose de calidad y nota.

```bash
raigal scan [opciones] [ruta]
```

Opciones:
- `--changes`: analiza únicamente los archivos modificados respecto a git `HEAD`.
- `--staged`: analiza únicamente los archivos preparados en git stage (ideal para pre-commit).
- `--base <ref>`: compara contra una rama o referencia específica (ejemplo: `origin/main`).
- `-d, --verbose`: muestra el desglose de archivos y líneas por regla.
- `--json`: devuelve el árbol completo de diagnósticos en JSON.
- `--sarif`: genera un informe en formato estándar OASIS SARIF 2.1.0.
- `--exclude <patrones>`: lista de rutas a ignorar separadas por coma o repetidas.
- `--include <patrones>`: lista de rutas a incluir expresamente.
- `--fail-on <nivel>`: devuelve código 1 según la gravedad mínima: `none`, `error` o `warning`.

### `raigal ci`

Ejecuta el control de calidad en runners de CI y devuelve código de salida 1 si no se cumplen los requisitos.

```bash
raigal ci [opciones] [ruta]
```

- Devuelve código de salida 1 si se detecta cualquier `error` o si la puntuación es menor que `ci.failBelow` (por defecto: 70).
- `--changes`: evalúa únicamente los archivos modificados respecto a `--base` (o `HEAD`).
- `--staged`: evalúa únicamente los archivos en stage.
- `--base <ref>`: referencia base para calcular el diff de `--changes` (ejemplo: `origin/main`).
- `--human`: muestra un resumen legible en la consola de CI en lugar de JSON crudo.
- `--sarif`: emite informe SARIF 2.1.0 por stdout para anotaciones en GitHub Code Scanning (ejemplo: `raigal ci --sarif > resultados.sarif`).
- `--format <formato>`: formato de salida: `json` (por defecto) o `sarif`.

*(La sincronización con Raigal Cloud ocurre automáticamente en CI al estar autenticado con OIDC o `RAIGAL_TOKEN`).*

### `raigal fix`

Aplica correcciones automáticas para formato, importaciones no utilizadas y comentarios obvios.

```bash
raigal fix [opciones] [ruta]
```

- `--safe`: aplica únicamente cambios deterministas que no alteran el comportamiento del código (por defecto).
- `-f, --force`: ejecuta correcciones más amplias, como actualización de dependencias y limpieza profunda.
- `--dry-run`: previsualiza qué cambiaría sin tocar los archivos en disco.
- `-p, --prompt`: convierte los problemas no corregibles automáticamente en un prompt para tu asistente de código.
- `--changes` / `--staged`: limita las correcciones a archivos modificados o en stage.
- `--base <ref>`: referencia base para calcular los cambios.

### `raigal agent`

Inicia sesiones de reparación automática con herramientas de IA locales en un git worktree aislado.

```bash
raigal agent [opciones] [ruta]
```

Opciones principales:
- `--provider <proveedor>`: proveedor a invocar (`auto`, `codex`, `claude`, `opencode`).
- `--target <n>`: nota mínima objetivo a alcanzar (por defecto: 90).
- `--max-turns <n>`: número máximo de turnos del agente por intento (por defecto: 5).
- `--max-cost <usd>`: tope de gasto en dólares que interrumpe la sesión si el consumo de tokens supera el límite.
- `--limit <n>`: número máximo de incidencias que se envían al agente (por defecto: 8).
- `--in-place`: modifica directamente el árbol de trabajo actual en lugar de crear un worktree aislado.
- `--apply`: aplica los cambios aceptados a tu rama actual al terminar.
- `-y, --yes`: omite preguntas de confirmación al usar `--apply`.
- `--dry-run`: muestra el plan de ejecución y el proveedor seleccionado sin aplicar cambios.
- `--background`: arranca el agente en segundo plano y devuelve el control al terminal de inmediato.
- `--no-fix`: omite los arreglos automáticos seguros previos antes de llamar al agente.
- `--commit`: crea un commit con los cambios verificados en una rama de reparación.
- `--pr`: publica la rama y abre un pull request en GitHub.
- `--branch <nombre>`: nombre de la rama para `--commit` o `--pr`.
- `--base <rama>`: rama base de destino para el pull request.
- `--title <titulo>`: título del pull request.
- `--commit-message <mensaje>`: mensaje del commit.
- `--ready`: abre el pull request como listo para revisión en lugar de borrador (draft).
- `--cleanup`: elimina el worktree temporal incluso si quedan cambios sin guardar.

Subcomandos:
- `raigal agent plan [dir]`: previsualiza proveedor, worktree y acciones sin modificar archivos.
- `raigal agent connect [proveedor]`: conecta con un proveedor local mediante su propia sesión de terminal.
- `raigal agent providers`: lista los proveedores de agentes detectados en el sistema y su estado.
- `raigal agent use [proveedor]`: define o consulta el proveedor predeterminado para este proyecto.
- `raigal agent sessions [dir]`: lista las sesiones de reparación activas y anteriores.
- `raigal agent show <session-id>`: muestra los cambios y diagnósticos de una sesión concreta.
- `raigal agent apply <session-id>`: fusiona los cambios de una sesión en tu rama de trabajo.
- `raigal agent monitor [dir]`: vigila cambios en git y analiza el código en segundo plano (añade `--auto-fix` para permitir ediciones automáticas).

### `raigal hook`

Gestiona hooks en tiempo real para Claude Code, Cursor, Gemini CLI y otras herramientas.

```bash
raigal hook <subcomando>
```

Subcomandos:
- `raigal hook install [agentes...]`: instala los hooks de intercepción (ejemplo: `raigal hook install --claude`).
- `raigal hook status`: comprueba los hooks instalados y la integridad de los centinelas SHA-256.
- `raigal hook baseline`: captura la deuda técnica actual en `.raigal/baseline.json`.
- `raigal hook uninstall [agentes...]`: desinstala los hooks limpiamente sin alterar la configuración del editor.

### `raigal report-pr-closed`

Notifica el cierre o fusión de un pull request a Raigal Cloud para actualizar el tablero de seguimiento.

```bash
raigal report-pr-closed [--pr <numero>] [--merged]
```

- `--pr <numero>`: número del pull request (se lee automáticamente de `GITHUB_EVENT_PATH` en GitHub Actions).
- `--merged`: indica si el pull request se fusionó en la rama base.

### `raigal login` y `raigal logout`

Gestionan las credenciales de Raigal Cloud y las licencias temporales sin conexión.

```bash
# Inicio de sesión interactivo con navegador
raigal login

# Inicio de sesión pasando el token por stdin
echo "rgl_live_..." | raigal login --with-token

# Cerrar sesión y limpiar credenciales locales
raigal logout
```

### `raigal whoami`

Muestra el usuario autenticado, organización activa, estado de la prueba o licencia y repositorios de GitHub con acceso autorizado.

```bash
raigal whoami
```

### `raigal doctor`

Verifica las dependencias del sistema, formateadores, linters y ejecutables de asistentes de código.

```bash
raigal doctor
```

### `raigal rules`

Muestra el catálogo completo de reglas, severidades, disponibilidad de corrección automática y niveles de impacto.

```bash
raigal rules
```
