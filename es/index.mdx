Raigal detecta los malos patrones que suelen dejar los asistentes de código de IA: comentarios obvios, errores silenciados en bloques catch, conversiones de tipos inseguras y llamadas de riesgo. Reúne formato, linters, análisis de complejidad y seguridad en un solo comando que devuelve una nota de 0 a 100.

Junto con [Raigal Cloud](https://app.raigal.dev) y la [GitHub App](https://github.com/apps/raigal-cloud), evalúa pull requests, bloquea fusiones si no se cumplen los mínimos de calidad, organiza los problemas en un tablero de 4 fases y coordina sesiones de reparación con agentes de código.

<Check>
  **Tu código fuente completo nunca se envía ni se almacena en los servidores de Raigal**. En las revisiones de pull requests, solo se envía un diff seguro con secretos enmascarados para mostrar los cambios en el panel.
</Check>

## Qué detecta Raigal

Herramientas como Claude Code, Cursor, Copilot u OpenCode aceleran el desarrollo, pero suelen dejar defectos repetitivos:

- Comentarios narrativos que solo repiten lo que ya dice el código.
- Bloques `catch` vacíos o excepciones silenciadas sin registrar.
- Aserciones de tipo laxas (`as any`, `as unknown as T`) para saltarse el tipado.
- Llamadas a `console.log`, código inaccesible o depuraciones olvidadas.
- Consultas SQL concatenadas, llamadas a `eval()` o herramientas de agentes sin aislamiento.

Raigal funciona en local mediante hooks para agentes, en CI en cada pull request y mediante escaneos directos en el terminal.

## Componentes

| Componente | Descripción | Enlace |
| --- | --- | --- |
| <strong>Raigal Cloud</strong> | Panel web en <code>app.raigal.dev</code> con seguimiento de problemas, historial de puntuación y métricas del equipo. | <a href="/es/cloud-platform/dashboard">Panel web</a> |
| <strong>GitHub App</strong> | Comprobaciones en pull requests, estados de commit y protección de ramas. | <a href="/es/automation-and-ci-cd/pull-requests">Instalación de la GitHub App</a> |
| <strong>Motor de puntuación (0-100)</strong> | Nota ponderada por densidad y número de archivos, con topes dinámicos y escala logarítmica. | <a href="/es/core-concepts/scoring">Motor de puntuación</a> |
| <strong>CLI y hooks para agentes</strong> | Comprobaciones pre-commit, correcciones automáticas (`raigal fix`) e intercepción en tiempo real de cambios de agentes. | <a href="/es/cli-reference/commands">Referencia de la CLI</a> |
| <strong>Reparación con agentes</strong> | Entornos git aislados donde agentes locales corrigen problemas y abren pull requests automáticamente. | <a href="/es/automation-and-ci-cd/agent-repairs">Reparación con agentes</a> |
| <strong>OIDC en GitHub Actions</strong> | Autenticación sin secretos fijos para runners de CI mediante tokens criptográficos de GitHub. | <a href="/es/core-concepts/security">Modelo de seguridad</a> |
| <strong>Servidor MCP</strong> | Servidor Model Context Protocol que conecta Raigal con Claude Code, Cursor, Windsurf, Cline y Antigravity. | <a href="/es/automation-and-ci-cd/mcp-server">Servidor MCP</a> |

## Primeros pasos

<Steps>
  <Step title="1. Inicia sesión en Raigal Cloud">
    Crea el espacio de trabajo de tu organización en [app.raigal.dev](https://app.raigal.dev) con una prueba de 14 días e invita a tu equipo. [Guía de configuración de la organización](/es/getting-started/first-client-setup)
  </Step>
  <Step title="2. Instala la GitHub App de Raigal">
    Conecta tus repositorios con la [GitHub App oficial de Raigal](https://github.com/apps/raigal-cloud) para revisar los pull requests automáticamente. [Control de calidad en pull requests](/es/automation-and-ci-cd/pull-requests)
  </Step>
  <Step title="3. Añade el flujo de CI">
    Configura GitHub Actions para evaluar cada pull request y enviar las notas al panel web. [Pipelines de CI/CD](/es/automation-and-ci-cd/ci-cd)
  </Step>
  <Step title="4. Configura las herramientas locales y hooks">
    Instala la CLI (`raigal scan`, `raigal fix`) y activa los hooks para Claude Code o Cursor. [Guía de inicio rápido](/es/getting-started/quickstart)
  </Step>
</Steps>
