title: "Installation"
description: "Install the Raigal CLI via npm, npx, pnpm, yarn, or bun on macOS, Linux, and Windows."
---

You can run Raigal directly without installing anything using `npx`, install it globally, or add it as a project dependency.

## System requirements

- **Node.js**: version 20.12 or higher (Node 22 LTS recommended)
- **Package manager**: `npm`, `pnpm`, `yarn`, or `bun`
- **Operating systems**: macOS, Linux, or Windows (PowerShell and cmd.exe)

## Run directly with `npx`

Run a scan immediately without installing packages:

```bash
npx --yes @methiu/raigal@latest scan .
```

Run the interactive setup wizard:

```bash
npx --yes @methiu/raigal@latest init
```

## Global installation

Install Raigal globally to make the `raigal` command available anywhere:

<Tabs>
  <Tab title="npm">

```bash
npm install -g @methiu/raigal
```

  </Tab>

  <Tab title="pnpm">

```bash
pnpm add -g @methiu/raigal
```

  </Tab>

  <Tab title="yarn">

```bash
yarn global add @methiu/raigal
```

  </Tab>

  <Tab title="bun">

```bash
bun add -g @methiu/raigal
```

  </Tab>
</Tabs>

Verify the CLI version:

```bash
raigal --version
```

## Project dependency

Add Raigal as a development dependency in your repository:

<Tabs>
  <Tab title="npm">

```bash
npm install -D @methiu/raigal
```

  </Tab>

  <Tab title="pnpm">

```bash
pnpm add -D @methiu/raigal
```

  </Tab>

  <Tab title="yarn">

```bash
yarn add -D @methiu/raigal
```

  </Tab>

  <Tab title="bun">

```bash
bun add -d @methiu/raigal
```

  </Tab>
</Tabs>

Add convenient scripts to your `package.json`:

```json
{
  "scripts": {
    "scan": "raigal scan .",
    "gate": "raigal ci .",
    "fix": "raigal fix ."
  }
}
```

Now anyone on the team can run `pnpm scan` or `npm run gate` with consistent settings.
